02 / 07
O problema

Uma auditoria em 4 etapas encadeadas

Antes do go-live de uma SPA, a agência entrega a auditoria. Um erro numa etapa cedo contamina o plano final.

ETAPA 1

Varredura

11 regras (FS01–FS11) no build: chaves vazadas, JWT de servidor, XSS, eval, CSP, HSTS, source map.

ETAPA 2

Dependências

Árvore do lock resolvida como o Node, cruzada com avisos. Diz se a lib vulnerável chega ao navegador.

ETAPA 3

Sessão

Cookies do login ao logout, lidos como o navegador: Secure, HttpOnly, SameSite, prefixos, expiração.

ETAPA 4

Plano

Mesma causa vira um item. Aplica exceções por data, prioriza por fórmula e dá a nota final.

modelo deepseek-v4.1-flash tempo 600 s custo US$ 0,50 sem internet escreve fora de out/ → zero
03 / 07
A sacada

O modelo não calcula.
Ele roda.

Agente que “pensa”

  • Lê arquivo minificado inteiro no contexto
  • Decodifica JWT e compara versão de cabeça
  • Erra um detalhe de regra e contamina o plano
  • Cada execução sai diferente
  • Estoura tempo e custo

Agente que roda o script

  • As 45 regras do README viram código testado
  • Mesma entrada → mesma saída, sempre
  • O modelo só executa 3 comandos e para
  • Termina em segundos, por centavos
  • Modelo fraco basta para acertar

O harness carrega a inteligência.
O modelo só precisa obedecer.

05 / 07
O que o script resolve

Os detalhes que derrubam um LLM

VARREDURA
  • Chave só no formato exato · pf_pub_ e placeholder não contam
  • JWT decodificado em base64url · role ausente também é crítico
  • XSS só com a fonte literal até o ;
  • CSP efetiva: script-src, senão default-src
DEPENDÊNCIAS
  • Resolução subindo node_modules, com ciclo
  • Caminho mais curto, empate em ordem de texto
  • 1.10.0 > 1.9.0 · faixas com ||
  • Banner /*! nome@versao decide o navegador
SESSÃO
  • Caminho padrão do cookie: /api/login → /api
  • Max-Age vale mais que Expires
  • Remoção só vale com a mesma identidade
  • Regras de __Host- e __Secure-
PLANO
  • XSS dentro de lib vulnerável soma no item dep:
  • Exceção: inexistente → crítica → vencida
  • ⌊pontos × 10 ÷ esforço⌋ e desempates
  • Item crítico força nota F
